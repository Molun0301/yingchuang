# 映窗

Windows、Linux 双端背屏壁纸编辑与转换工具。读取本机 Wallpaper Engine（动态壁纸引擎）主题，调整取景、日期、时间和字体，保存排版模板并批量导出小米背屏主题。

## 功能

- 自动发现 Steam 的常规安装、多库、Flatpak 和 Snap 安装目录。
- 主题参数、图层、字体、颜色与时间位置编辑。
- 仅排版模板、收藏、全选、多选、批量转换和任务取消。
- 内置小米 17 Pro、17 Pro Max、18 Pro、18 Pro Max 背屏尺寸。
- 场景、图片与视频转换，导出可交给 RearEye 导入的 `.mrc` 文件。
