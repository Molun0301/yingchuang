映窗 0.1.1

Windows：解压免安装包，打开“映窗.exe”。请保留同目录的资源文件。
Linux：运行 AppImage。程序已包含转换运行时，无需另装 Python。

启动后自动读取本机 Steam 壁纸目录，也可添加目录。点击封面编辑，保存排版模板；多选后选择模板与机型即可批量转换。成品为 .mrc，在 RearEye 壁纸管理器中导入。

在预览画面上滚动鼠标滚轮可缩放场景。右侧“时间”页集中编辑星期、日期和时间的字体、字号、颜色、位置与格式；旧草稿若关闭了时间，打开“日期与时间”开关即可编辑。

支持机型：小米 17 Pro、17 Pro Max、18 Pro、18 Pro Max。预览和导出按所选机型尺寸布局。

原主题参数均从工程读取。复杂三维、自定义着色器及持续脚本仍受转换器能力限制，具体项目列在成品目录“转换报告.json”。
Windows和Linux实际打包程序已通过界面检查。手机导入与背屏运行尚未实机验证。

开发

安装 Node.js 与 Python 3.12，运行 npm ci，并在项目 .venv 中安装 core/requirements.txt。
先运行 python scripts/编译网格.py linux（Windows用 win，需安装 ziglang==0.13.0），再运行 npm run build 和 npm start。
桌面测试：npm test
转换测试：python -I -m pytest tests --basetemp=test-results/pytest -q
真实主题测试可用 YINGCHUANG_TEST_THEME 指定猫猫工程目录。
打包运行时：python -I scripts/准备运行时.py linux 或 win。
打包应用：npm run package:linux 或 npm run package:win。
Linux 发布构建建议使用便携 Python 或在目标最低系统版本上构建。
