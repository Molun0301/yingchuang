映窗 0.3.0

Windows：解压免安装包，打开“映窗.exe”。请保留同目录的资源文件。
Linux：运行 AppImage。程序已包含转换运行时，无需另装 Python。

启动后自动读取本机 Steam 壁纸目录，也可添加目录。点击封面编辑，保存排版模板；多选后选择模板与机型即可批量转换。成品为 .mrc。导入手机的方法（未 root、Shizuku 授权、已 root 用 REAREye）见 docs/公开文档/背屏导入指南.md。

编辑器实时渲染壁纸的完整特效。默认“图层模式”逐层还原特效，背屏上每层独立感应视差；“录制模式”把完整画面录为循环视频，适合网页、应用壁纸。随时间变化的壁纸可在预览工具条拖动“预览时刻”查看各时段，导出后背屏按系统时间切换。导出页可选省空间、标准、高清三档画质。

在预览画面上滚动鼠标滚轮可缩放场景。右侧“组件”页可添加时间、日期、星期、农历、步数、天气、电量等组件，并分别设置字体、字号、颜色、位置与格式；步数与天气数据由手机系统提供，电脑预览显示示例数据。“排版”页可水平翻转画面，预览工具条“避让区域”显示真机镜头位置。设置页“关于与更新”可检查新版本。

支持机型：小米 17 Pro、17 Pro Max、18 Pro、18 Pro Max。预览和导出按所选机型尺寸布局。

作用于整幅画面的后期层、鼠标交互与实时音频频谱无法拆到图层，具体项目列在成品目录“转换报告.json”。
Linux 上运行 AppImage 需要 FUSE 2（Ubuntu 24.04 及以上安装 libfuse2t64）。手机导入与背屏运行尚未实机验证。

开发

安装 Node.js 与 Python 3.12，运行 npm ci，并在项目 .venv 中安装 core/requirements.txt。
先运行 python scripts/编译网格.py linux（Windows用 win，需安装 ziglang==0.13.0），再运行 npm run build 和 npm start。
桌面测试：npm test
转换测试：python -I -m pytest tests --basetemp=test-results/pytest -q
真实主题测试可用 YINGCHUANG_TEST_THEME 指定猫猫工程目录。
打包运行时：python -I scripts/准备运行时.py linux 或 win。
打包应用：npm run package:linux 或 npm run package:win。
Linux 发布构建建议使用便携 Python 或在目标最低系统版本上构建。
