# 映窗 0.5.1

本版修复两个问题：部分壁纸导出到背屏后动画卡顿；壁纸自带的时间文字做了三维旋转时，开启组件后时间行消失。

## 修复

- **背屏动画卡顿**：图层多、画面大的壁纸（如 Dome、孤独の少女、Lost Cat. 8），整幅背景层导出后每秒只有约 3 帧，播放时一顿一顿。现在：
  - 帧率受限的图层在相邻两帧之间交叉淡化，云、灯光、光束这类缓慢变化的画面连贯播放；透明的粒子层旧帧同步淡出，不留拖影。电脑预览与背屏效果一致。
  - 骨骼动画人物下面挂着的粒子、裙摆等子层，烘焙时不再把人物一起画进去（Dome 里人物原来被重复存了 7 份）。省下的内存留给背景层，Dome 的整幅背景从 724×431 提高到 1055×628。
  - 内存预算先满足小图层，余下的分给大图层；抽帧按预算直接算出帧数，预算不再浪费。
- **组件时间行消失**：壁纸自带的时间文字做了三维旋转时（如午后时光），开启组件后“时间”行被当成隐藏，现在正常显示，字体也能沿用原壁纸的。
- **预览角标**：预览右上角的角标和加载状态条不再拦截鼠标，窗口较小时也能在预览上滚动缩放、拖动组件。

## 说明

- 已导出的壁纸重新导出后才有上述改进。更新后第一次导出会重新烘焙图层，耗时比平时长。
- 使用说明已改写：导入步骤统一按澎湃 OS 4 说明，替换法适用全部机型。
- 下载链接固定指向最新版：yingchuang-Windows-x64.zip、yingchuang-Linux-x86_64.AppImage。

## 验证

- 181 项转换测试、68 项桌面测试通过。
- Linux 打包版实际导出通过；Windows 包与手机端背屏显示尚未实机验证。
