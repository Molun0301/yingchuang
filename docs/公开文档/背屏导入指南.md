# 映窗使用说明

映窗把电脑上的 Wallpaper Engine 壁纸转换成小米背屏主题包（`.mrc`），适用于小米 17 Pro、17 Pro Max、18 Pro、18 Pro Max（澎湃 OS 4）。

## 一、导出背屏包

1. 下载并打开映窗（[Windows / Linux](https://github.com/Molun0301/yingchuang/releases/latest)），它会自动读取 Steam 里的 Wallpaper Engine 壁纸。
2. 在“设置 → 机型”选择你的手机。
3. 点开壁纸，调整画面、组件和壁纸设置，改动自动保存。
4. 点“转换壁纸”，导出目录里得到 `壁纸名 · 机型.mrc`。

## 二、导入手机

导入用替换法：先用妙享背屏的“AI 生图”生成一张壁纸，系统会为它建好背屏模板，再把模板文件换成映窗导出的 `.mrc`。

模板放在 `Android/data` 里，普通文件管理器没有权限：

- 未 root：用 Shizuku 授权的文件管理器（如 MT 管理器）。Shizuku 通过无线调试取得权限，安装后按引导启动，再给文件管理器授权。
- 已 root：用 root 文件管理器。

替换步骤：

1. 打开妙享背屏，用“AI 生图”生成一张壁纸。
2. 进入 `Android/data/com.android.thememanager/files/MIUI/.ai_wallpaper/maml/`，打开刚生成的壁纸文件夹（里面有 `rearscreen` 和 `description.xml`，文件夹多时按修改时间找最新的）。
3. 把 `rearscreen` 改名为 `rearscreen.bak` 备份。
4. 把映窗导出的 `.mrc` 复制进来，改名为 `rearscreen`（不带后缀）。`.mrc` 本身是 ZIP 包，直接改名，不要解压。
5. 回到妙享背屏，背景选“AI 生图”，选中这张壁纸。

换回原来的壁纸：删除 `rearscreen`，把 `rearscreen.bak` 改回原名。

## 三、已 root：用 REAREye 导入

[REAREye](https://github.com/killerprojecte/REAREye) 是基于 LSPosed 的背屏增强模块，可以直接导入 `.mrc`：

1. 在 LSPosed 中启用 REAREye，作用域勾选 `android`、`com.xiaomi.subscreencenter`、`com.android.thememanager`、`com.android.systemui`，重启手机。
2. 打开 REAREye → 壁纸管理器 → 导入 MRC / ZIP 壁纸包，选择导出的 `.mrc` 并设为当前壁纸。
