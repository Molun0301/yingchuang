# 映窗 0.4.0

本版让“随时间变化”的壁纸普遍可用，图层模式预览改为秒开，导出改为多项并行，界面新增参照 iOS 26 重做的液态玻璃。

## 新功能

- **随时间变化（实验）**：编辑器顶部新增开关，所有场景壁纸都可开启。开启后在一天中 8 个时刻（1:30、4:30 … 22:30）分别渲染壁纸，背屏按系统时间切换画面；两个时刻之间的切换时间按壁纸脚本推算。开关打开时预览下方出现时间条，可拖动查看各时段。
  - 壁纸自带“时间模式”且默认不跟随现实时间的（如“自选时间段”），开启时自动改为现实时间并提示改了哪一项。
  - 调色类全屏图层（夜晚色调等）测出色彩变化后套到下方各图层，不再在导出时丢失。
- **图层模式秒开**：图层模式预览改用实时渲染，打开编辑器即可编辑；倾斜手机时按各图层景深分别移动，与背屏一致。逐层渲染只在导出时进行。
- **按实际周期循环**：图层动画按自身周期录制（12 秒内检测），首尾无缝衔接；找不到周期的仍按 4 秒首尾过渡。
- **并行导出**：多个壁纸按 CPU 核数同时导出（最多 3 个），逐层渲染窗口全局限量，显存占用不随导出数成倍增加。
- **组件中英文**：含文字的 15 个组件可分别选择中文或英文（星期、农历、天气、步数等）。
- **更新公告**：更新后首次启动显示该版本的更新说明。自动更新失败时可直接打开 GitHub 发布页或夸克网盘手动下载。
- **液态玻璃**：参照 iOS 26 重做：玻璃本体透明，边缘按凸透镜折射并带色散，左上与右下镜面高光随指针变化，控件为胶囊形；壁纸库的工具条悬浮在卡片上方。原来的液态玻璃改名为磨砂玻璃，原磨砂玻璃移除。
- **组件卡片**：点一次切换到该组件，在该组件的编辑页再点一次取消显示。

## 修复

- 部分壁纸的下拉选项值被当成数字，作者写的时间模式等设置不生效（如孤独の少女在电脑端不随时间变化）。
- 透明度为 0 的图层下面的人物在导出后缺失（Postscript）。
- 带抠色或透明度效果的视频图层在背屏上露出背景色块（孤独の少女左侧青色块）。
- 每次渲染都带随机成分的图层，逐层渲染后出现针孔状小洞。
- 多个导出同时进行时，渲染缓存被误删导致导出失败。

## 说明

- 随时间变化为实验功能：导出时间和包体会增加；短于 3 小时的时段可能采不到。
- 按周期录制需要多观察几秒画面，渲染开销大的壁纸导出会变慢（孤独の少女约 44 秒 → 81 秒）。

## 验证

- 167 项转换测试、63 项桌面测试通过。
- Linux 打包版实际导出通过；Windows 包与手机端背屏显示尚未实机验证。
