# 映窗 0.5.0

本版按实际使用重新梳理了编辑器、壁纸库和导出流程：改动自动保存、可以撤销，组件能在预览上直接点选拖动，新增成品页集中管理导出结果；镜头位置改用小米官方背屏主题的实测数据。

## 新功能与改进

- **自动保存**：编辑器去掉“完成”，改动随时保存，Ctrl+Z / Ctrl+Shift+Z 撤销重做。转换时留在编辑器显示阶段与进度，可随时取消。
- **在预览上排版**：直接点选组件或图层，拖动时自动吸附并显示参考线；按住 Shift 点选或框选多个组件一起移动；方向键微调 1 像素，加 Shift 为 10 像素。
- **组件**：改为“已添加的组件 + 添加组件”，选中组件的设置紧跟在列表下方；文字新增阴影、描边效果。
- **排版模板**：编辑器里悬停模板即可预览，点一下套用，可撤销；壁纸库多选后“套用排版”与“转换”分开。
- **成品页**：侧栏改为壁纸库、我的收藏、成品、设置。成品页保留每张壁纸在各机型上最近一次导出，可回放、查看还原差异、在文件夹中显示；导出目录只放一个“标题 · 机型.mrc”。
- **设置页**：用机型卡片选择机型（机型改为全局设置），排版模板也在这里管理。
- **壁纸库**：标注预设、已导出和不可用的壁纸；壁纸目录有增删时自动刷新；按创意工坊编号识别壁纸。
- **导出**：导出页精简，显示上次导出的包大小；导出完成时发送系统通知，任务栏显示进度。
- **真机镜头**：四款机型的镜头位置与大小改用小米官方预装背屏主题按机型制作的素材实测，避让线与系统给镜头留的宽度一致。18 Pro 的镜头原来偏左，已修正。
- **随时间变化**：图层页把本该由壁纸按时间切换的图层固定成显示或隐藏时，编辑器会提示并可一键恢复；开启随时间变化时自动恢复。
- 旧版本的作品和模板在首次启动时自动迁移。

## 修复

- 部分随时间变化的壁纸（如春至、窗旁の伊蕾娜）拖动时间条画面不变：混合效果引用的时段视频没有播放，已在渲染库中修正。
- 依赖原壁纸的预设壁纸无法编辑；原壁纸缺失时，卡片会标出“缺原壁纸”，并可打开 Steam 页面。
- 编辑器在载入失败等情况下无法关闭。
- 提示条文字被玻璃背景盖住；“添加组件”弹层被下方设置项盖住。
- 低分辨率封面放大后出现马赛克；预览角标显示调试信息。
- 组件改动要等半秒才显示；出现转换说明时预览跳动；拖动预览时刻时组件里的时钟不跟随。
- Linux 上的应用壁纸可以点选却无法录制，现在置灰并说明只能在 Windows 上录制。

## 说明
