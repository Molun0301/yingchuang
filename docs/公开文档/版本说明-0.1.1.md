# 映窗 0.1.1

本版修复图层缺失、场景内嵌视频导出、时间编辑入口和下拉菜单显示问题，并缩短打开编辑器时的等待。

## 修复

- 骨骼网格按透明度叠加，避免上层透明区域擦除脸部、眼睛等内容；快速预览也会先正确拼合骨骼网格。
- 支持场景内嵌视频纹理，修复《魔女之旅》样例导出失败。名称为 `day` 的图片不再被误当作星期文字而隐藏。
- 读取本机壁纸引擎自带字体，保留原主题时钟字体；支持统一数值绑定的图层缩放和视差。
- 编辑器增加独立“时间”页，画面支持鼠标滚轮缩放。
- 下拉菜单在窗口顶层展开，支持搜索和键盘操作；窗口按屏幕可用区域打开，并适配小窗口。
- 第一帧完成后再处理完整动效，动画图片分批解码；导出仍等待完整转换。
- 精简不需要的运行依赖、调试版本、语言包及依赖测试文件。应用仍包含离线转换所需组件。

## 转换范围

鼠标拖尾、鼠标波纹等交互按产品范围忽略。自定义着色器、部分特效叠加、实时音频驱动、三维场景、脚本事件及持续运行逻辑仍有未迁移项；每次导出的转换报告会记录具体差异。本版集中修复已有流程，全面特效支持另行推进。

## 验收边界

场景首帧、完整动效、导出资源和手机实际运行分别验证。桌面生成文件成功不代表所有特效已还原，也不代表手机实时频谱已通过。具体构建与测试结果以版本页的发布记录为准。
