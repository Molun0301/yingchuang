# 映窗 v0.1.0

首个公开发行版本，提供 Windows 与 Linux 桌面应用，程序包自带转换运行时。

## 下载应用

| 系统 | 下载 | 使用方式 |
| --- | --- | --- |
| Windows x64 | [下载免安装包](https://github.com/Molun0301/yingchuang/releases/download/v0.1.0/yingchuang-0.1.0-Windows-x64.zip) | 完整解压后打开“映窗.exe” |
| Linux x86_64 | [下载便携应用包](https://github.com/Molun0301/yingchuang/releases/download/v0.1.0/yingchuang-0.1.0-Linux-x86_64.AppImage) | 赋予执行权限后运行 |

## 功能

- 自动识别本机主题库，支持搜索、收藏、多选与全选。
- 编辑主题设置、图层、取景、时间位置、字体与颜色。
- 保存仅排版模板并批量转换，支持取消任务。
- 内置小米 17 Pro、17 Pro Max、18 Pro、18 Pro Max 机型预设。
- 输出 `.mrc` 主题包，可通过 RearEye 壁纸管理器导入。

Linux 启动与主要流程、47 项自动检查已通过；Windows 原生运行和手机导入尚未实测。复杂三维、自定义着色器、脚本事件及持续脚本未完整迁移，具体差异见每个成品目录的“转换报告.json”。
