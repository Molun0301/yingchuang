# 映窗 0.2.0

本版重做界面，并让导出结果尽量还原电脑上的壁纸效果：特效完整渲染、逐层保留感应视差、随时段变化的画面导出后照样切换，同时大幅缩短转换时间。

宣传片：[B 站观看](https://www.bilibili.com/video/BV1JrWM6DE6N/) · 导入手机的方法见 [背屏导入指南](背屏导入指南.md)。

## 新功能

- **完整特效渲染**：编辑器内置 WebGL 渲染器，实时显示壁纸的特效、粒子、脚本与网页内容。
- **图层模式还原特效**：每个图层单独渲染特效后分层导出，背屏上每层独立随倾斜视差，默认画面与录制模式一致。
- **随时段变化**：脚本按时间切换画面的壁纸（如《魔女之旅》伊蕾娜系列）会采样一整天，导出后背屏按系统时间切换，渐变时段保留过渡；编辑器可拖动“预览时刻”查看各时段。
- **录制模式**：网页、应用和透视三维壁纸可录制为首尾无缝的循环视频。
- **导出压缩**：按背屏实际分辨率裁切与缩小贴图和视频，提供省空间、标准、高清三档画质。
- **玻璃界面**：磨砂玻璃、液态玻璃两种材质，浅色、深色或跟随系统。

## 性能

- 打开主题库时预先解析悬停的壁纸，点开编辑器更快；Linux 版启动时间从数十秒降到约 1.5 秒。
- 图层特效由多个窗口并行渲染，结果按图层缓存，修改设置后只重新渲染变化的部分。
- 视频优先使用显卡硬件编码（NVENC / QSV / AMF），多段视频并行转码。
- 测试机（i9-14900K、RTX 4090）冷缓存导出：含 4 段 4K 视频与 23 种时段画面的壁纸 26 秒，此前 66 秒。

## 修复

- 图层模式下天空发黑、出现黑块或暗点，与录制模式不一致。
- 编辑页移动鼠标时应用背景变色；缩放小于 100% 时露出预览动图；部分特效在编辑中途消失。
- 成品目录里的交互预览按当前时刻显示随时段变化的画面，此前各时段画面会叠在一起。

## 验证

- 112 项转换测试、15 项桌面测试通过。
- Linux 打包程序实际导出 4 款真实壁纸，画面与资源检查通过。
- Windows 安装包尚未在 Windows 上实际运行；手机导入、背屏运行与时段切换尚未实机验证。
