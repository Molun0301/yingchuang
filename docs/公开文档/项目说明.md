# 映窗项目说明

映窗把本机已有的 Wallpaper Engine（动态壁纸引擎）主题转换为小米背屏主题。界面使用磨砂玻璃风格，支持预览、主题设置、图层编辑、独立时钟排版与批量转换。

## 使用流程

1. 启动应用，自动读取本机主题库；也可以手动添加目录。
2. 点击主题，选择目标机型，调整构图、字体、颜色和日期时间位置。
3. 保存排版模板，或在主题库多选后选择模板进行批量转换。
4. 在导出目录取得 `.mrc` 文件，通过 RearEye 的壁纸管理器导入手机。

排版模板保存取景、时钟显示状态、位置、字号和对齐。主题参数、字体、颜色及机型分别保留在每个主题的编辑设置中。

## 源码运行

建议使用 Node.js 24（前端开发运行环境）和 Python 3.12（脚本运行环境）。在项目根目录安装依赖。

Linux：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r core/requirements.txt
npm ci
.venv/bin/python scripts/编译网格.py linux
npm run build
npm start
```

Windows 构建还需 Zig（交叉编译工具链），它只用于生成网格渲染库，不进入应用包。

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r core/requirements.txt ziglang==0.13.0
npm ci
.venv\Scripts\python.exe scripts/编译网格.py win
npm run build
npm start
```

应用在首次使用时读取本机主题与字体。部分场景还会读取 Wallpaper Engine 安装目录中的内置资源。

## 构建应用包

先准备随应用分发的转换运行时。Linux 构建需要额外安装 PyInstaller（Python 程序打包工具）。

```bash
.venv/bin/python -m pip install pyinstaller==6.16.0
.venv/bin/python -I scripts/准备运行时.py linux
npm run package:linux
```

Windows 构建还需 Zig（交叉编译工具链），它只用于生成网格渲染库，不进入应用包。

```powershell
.venv\Scripts\python.exe -m pip install ziglang==0.13.0
.venv\Scripts\python.exe -I scripts/准备运行时.py win
npm run package:win
```

Windows 运行时使用官方嵌入式 Python 和对应平台依赖。Linux 发布构建建议使用便携 Python，或在计划支持的最低系统版本上构建。构建结果位于 `release/`，应用包已包含转换运行时。

## 验证

桌面功能与脚本处理：

```bash
npm test
```

转换回归：

```bash
.venv/bin/python -m pip install pytest==8.4.2
.venv/bin/python -I -m pytest tests --basetemp=test-results/pytest -q
```

真实主题回归需要本机猫猫样例，可通过 `YINGCHUANG_TEST_THEME` 环境变量指定该主题目录。没有样例时，对应检查会跳过。

## 转换范围

当前支持可解析的平面场景、图片和视频，以及已有的图层动效、字体字形和传感器视差。原主题公开参数从工程读取，支持的场景脚本按当前设置解析初始状态。编辑器先生成真实场景第一帧，后台继续生成动效；鼠标交互按产品范围忽略。

任意三维、自定义着色器、脚本事件与持续运行逻辑尚未完整迁移；实时音频驱动等差异会列在转换报告中。全面特效支持已暂缓，当前版本继续使用现有 RearEye 主题包。Windows实际打包程序已通过窗口与转换检查。RearEye手机导入、背屏性能、传感器方向和息屏恢复仍需对应设备实测。

## 第三方组件

应用使用 Electron（桌面应用框架）、React（界面库）、QuickJS（脚本解释器）以及 Python 图像和音视频组件。第三方许可证位于 [许可目录](../../build/licenses/)。纹理格式解析参考 RePKG，其许可证保存在 [RePKG 许可证](../../core/RePKG许可证.txt)。
