# 映窗项目说明

映窗把本机已有的 Wallpaper Engine（动态壁纸引擎）主题转换为小米背屏主题。界面提供磨砂玻璃与液态玻璃两种材质，支持完整特效预览、主题设置、图层编辑、背屏组件排版与批量转换。

## 使用流程

1. 启动应用，自动读取本机主题库；也可以手动添加目录。
2. 点击主题，选择目标机型，调整构图，添加时间、农历、步数、天气等组件并设置字体、颜色和位置。
3. 保存排版模板，或在主题库多选后选择模板进行批量转换。
4. 在导出目录取得 `.mrc` 文件，通过 RearEye 的壁纸管理器导入手机。

排版模板保存取景、组件显示状态、位置、字号和对齐。主题参数、字体、颜色及机型分别保留在每个主题的编辑设置中。

## 机型预设

| 机型 | 背屏画布 |
| --- | --- |
| 小米 17 Pro | 904 × 572 |
| 小米 17 Pro Max | 976 × 596 |
| 小米 18 Pro | 912 × 596 |
| 小米 18 Pro Max | 976 × 596 |

规格来源保存在 [机型配置](../../desktop/devices.json)。预览中的避让区域按机型画出镜头位置：镜头半径与避让宽度来自系统背屏主题数据，17 Pro、18 Pro 的镜头圆心为推算值。

## 源码运行

建议使用 Node.js 24（前端开发运行环境）和 Python 3.12（脚本运行环境）。在项目根目录安装依赖。

Linux：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r core/requirements.txt
npm ci
.venv/bin/python scripts/编译网格.py linux
npm run build
npm start
```

Windows 构建还需 Zig（交叉编译工具链），它只用于生成网格渲染库，不进入应用包。

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r core/requirements.txt ziglang==0.13.0
npm ci
.venv\Scripts\python.exe scripts/编译网格.py win
npm run build
npm start
```

应用在首次使用时读取本机主题与字体。部分场景还会读取 Wallpaper Engine 安装目录中的内置资源。

## 构建应用包

先准备随应用分发的转换运行时。Linux 构建需要额外安装 PyInstaller（Python 程序打包工具）。

```bash
.venv/bin/python -m pip install pyinstaller==6.16.0
.venv/bin/python -I scripts/准备运行时.py linux
npm run package:linux
```

Windows 构建还需 Zig（交叉编译工具链），它只用于生成网格渲染库，不进入应用包。

```powershell
.venv\Scripts\python.exe -m pip install ziglang==0.13.0
.venv\Scripts\python.exe -I scripts/准备运行时.py win
npm run package:win
```

准备运行时会下载 BtbN 的 GPL 版 FFmpeg（含硬件编码器）放入运行时目录。Windows 运行时使用官方嵌入式 Python 和对应平台依赖。Linux 发布构建建议使用便携 Python，或在计划支持的最低系统版本上构建。构建结果位于 `release/`，应用包已包含转换运行时。

## 验证

桌面功能与脚本处理：

```bash
npm test
```

转换回归：

```bash
.venv/bin/python -m pip install pytest==8.4.2
.venv/bin/python -I -m pytest tests --basetemp=test-results/pytest -q
```

真实主题回归需要本机猫猫样例，可通过 `YINGCHUANG_TEST_THEME` 环境变量指定该主题目录。没有样例时，对应检查会跳过。

## 转换范围

场景壁纸默认使用图层模式：每个可见图层在隐藏窗口中用 WebWallGL 单独渲染特效（黑底、白底各渲染一次求出透明度），按 4 秒循环烘焙，背屏逐层绘制并分别响应感应。脚本读取时间的壁纸会按 15 分钟采样一整天，各时段画面导出为图层变体，背屏按 `#hour24`、`#minute` 计算透明度切换。作用于整幅画面的后期层、鼠标交互与实时音频无法拆到图层，列在转换报告中。

录制模式把完整画面录制为循环视频，适合网页、应用和透视三维壁纸。视频壁纸直接转码。导出时按背屏实际分辨率裁切与缩小资源；视频优先使用显卡硬件编码，没有可用硬件编码器时使用 libx264。

RearEye 手机导入、背屏性能、传感器方向、时段切换和息屏恢复仍需对应设备实测。

## 第三方组件

应用使用 Electron（桌面应用框架）、React（界面库）、WebWallGL（壁纸渲染器）、QuickJS（脚本解释器）以及 Python 图像和音视频组件。映窗源码以 [MIT 许可证](../../LICENSE) 发布；第三方许可证位于 [许可目录](../../build/licenses/)，随包的 FFmpeg 可执行程序按 GPL-3.0 授权。纹理格式解析参考 RePKG，其许可证保存在 [RePKG 许可证](../../core/RePKG许可证.txt)。
