# 映窗 0.3.0

本版把时钟扩展为背屏组件，预览按真机画出镜头位置，增加画面翻转与在线更新，主题字体有问题时不再中断转换。

## 新功能

- **背屏组件**：编辑器“时间”页改为“组件”，共 20 个组件，可分别设置位置、字体、字号、颜色、对齐和是否显示单位：
  - 时间日期：时间、日期、星期、农历
  - 运动健康：步数、运动距离、消耗热量、中高强度运动、步数目标（数据来自小米健康）
  - 天气：天气、气温、今日温度、湿度、空气质量、日出、日落（数据来自小米天气）
  - 手机状态：电量、未读短信、未接来电
  - 自定义文字
- **真机镜头**：“避让区域”按各机型的实际位置画出两枚镜头和避让边界，屏幕圆角与真机一致，默认开启。
- **画面翻转**：“排版”页可水平翻转壁纸，主体被镜头挡住时移到另一侧；时间与组件不翻转。图层模式与录制模式导出结果一致。
- **在线更新**：启动时检查 GitHub 正式版（可在设置中关闭），发现新版本后可查看更新说明、下载并自动安装；下载文件按发布页提供的摘要校验。Linux AppImage 自动替换后重启，Windows 免安装包退出后自动覆盖。

## 修复

- 主题字体缺失、无法确定或缺少数字字形时（如 Pastel Bloom），预览不显示时间、导出中断。现在改用本机备用字体继续生成，并在“转换说明”中提示，可一键跳到字体选择。

## 说明

- 健康、天气、短信与来电数据由手机系统提供，电脑预览显示示例数据。手机需安装小米健康、小米天气并授予相应权限。
- 小米 17 Pro / Pro Max、18 Pro Max 的镜头半径与避让宽度来自系统背屏主题数据；17 Pro、18 Pro 的镜头圆心为推算值。

## 验证

- 129 项转换测试、18 项桌面测试通过。
- Linux 实际导出带翻转与组件的壁纸，背屏清单、数据源与静态预览检查通过；在线更新实际下载并替换 AppImage 成功。
- Windows 安装包与自动更新脚本尚未在 Windows 上实际运行；组件数据读取、手机导入与背屏运行尚未实机验证。
